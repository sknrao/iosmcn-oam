# Energy-saving rApp

This directory holds just support structure for the real ES rApp, since proprietary nature of it prevented us to include it. Contrary to TS-rApp, this directory does not include any implementation whatsoever, since everything was implemented as proprietary.

What can be revealed is, that application worked as 2 processes, the main one was used for communication with surroundings and doing main logic stuff, but offloading prediction computation to separate process.
